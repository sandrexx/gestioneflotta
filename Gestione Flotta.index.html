🔑 Come ottenere l'API Key

1. Vai su console.cloud.google.com
2. Crea un progetto → Abilita "Google Drive API" e "Google Sheets API"
3. Credenziali → Crea chiave API
4. Rendi pubblici i file Drive (condividi → chiunque con il link può visualizzare)
5. Inserisci la chiave qui sotto e salva
